# AI Digital Skills Project

A hands-on Python learning repository for the NM1130 - AI and Digital Skills course (Naan Mudhalvan), designed to help students understand key concepts in artificial intelligence, productivity tools, cybersecurity, GitHub fundamentals, Power BI, and career readiness.

This project contains practical experiments and mini-projects that demonstrate real-world AI and digital skills using Python.

## Overview

The repository is organized as a set of self-contained Python exercises. Each script focuses on a specific concept and includes sample output, explanations, and small use cases that can be run directly on a local machine.

## Project Modules

| No. | Topic | File | What it demonstrates |
|------|-------|------|---------------------|
| 1 | AI Fluency | `01.ai_fluency.py` | AI history, classification, regression, clustering, optimization, neural networks, and NLP sentiment analysis |
| 2 | AI Productivity | `02.ai_productivity.py` | AI-style productivity assistant for email drafting, summarization, action items, proposals, and sales insights |
| 3 | AI Applications | `03.ai_applications.py` | AI use cases in healthcare, banking fraud detection, recommendations, and agriculture |
| 4 | LinkedIn Branding | `04.linkedin_profile_analyzer.py` | LinkedIn profile scoring, common mistakes, headline generation, and profile improvement analysis |
| 5 | Cybersecurity | `05.cybersecurity_toolkit.py` | Password strength checking, secure password generation, phishing detection, TOTP, and hashing |
| 6 | GitHub Foundations | `06.mini_git.py` | Mini Git simulation covering commit, branch, merge, conflict resolution, clone, PR, and review workflow |
| 7 | Power BI | `07.power_bi_dashboard.py` | Data cleaning, KPI calculation, and dashboard generation using a Power BI-style workflow |
| 8 | Career Essentials | `08.career_essentials.py` | Career self-assessment, skill gap analysis, SMART goals, and priority planning |
| 9 | Sample Python | `HelloWorld.py` | Basic Python starter example |

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/praveenrp23/AI-Digital-Skills-Project.git
cd AI-Digital-Skills-Project
```

### 2. Create and activate a virtual environment

```bash
python -m venv .venv
```

On Windows:

```bash
.venv\Scripts\activate
```

On macOS/Linux:

```bash
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

## Running the Project

You can run each experiment individually:

```bash
python 01.ai_fluency.py
python 02.ai_productivity.py
python 03.ai_applications.py
python 04.linkedin_profile_analyzer.py
python 05.cybersecurity_toolkit.py
python 06.mini_git.py
python 07.power_bi_dashboard.py
python 08.career_essentials.py
python 08.career_essentials.py --interactive
```
